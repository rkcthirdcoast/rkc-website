# rkcthirdcoast.com

Website for RKC Third Coast FC: USL League Two, USL W League and Midwest Premier League soccer at Pritchard Park Stadium in Racine, Wisconsin.

Static site. Launching March 2027, replacing the Duda site.

- Stylesheet: [`rkc.css`](rkc.css)
- Component sample: [`style-sample.html`](style-sample.html)

Every change goes through a pull request and is approved by Tim Gallion (or Wayne Howard) from its preview link before it goes live.
